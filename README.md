# ISU4YearPlan

A simple website to help Iowa State students build and save a 4-year graduation plan.

## Features
- Create an account and log in
- Pick a major and view recommended classes
- Add classes to any semester in a 4-year schedule
- Autosave and return to your plan later (stored in browser local storage)

## Run locally
Because this is a static site, you can open `/home/runner/work/ISU4YearPlan/ISU4YearPlan/index.html` directly in a browser.
